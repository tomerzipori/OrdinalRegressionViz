# OrdinalRegressionViz — package professionalization design

Date: 2026-07-31
Branch: `feature/package-professionalization`
Goal: turn the experimental visualization collection into a professional, research-ready R package.

## Context

OrdinalRegressionViz provides ggplot2 visualizations for ordinal probit (SDT-style) regression models — frequentist (`ordinal::clm`/`clmm`) and Bayesian (`brms`) — plus a Bayesian meta-analytic forest plot. The plots were built for Simchon, Zipori, Teitelbaum, Lewandowsky & van der Linden (2026), "A signal detection theory meta-analysis of psychological inoculation against misinformation", *Current Opinion in Psychology*, 67, 102194 (doi:10.1016/j.copsyc.2025.102194).

Current state: 6 exported functions, working but publication-specific. No tests, no vignette, no CI, placeholder DESCRIPTION, broken NAMESPACE (`import(tidyverse)`, undeclared deps), hardcoded study-specific labels/coefficient names, several latent bugs.

## What ships on this branch

### 1. Metadata

- `DESCRIPTION`: real Title/Description; `Authors@R` (Tomer Zipori, aut+cre); `License: MIT + file LICENSE`; `URL`/`BugReports` (GitHub); complete `Imports` (add ggridges, glue, RColorBrewer, insight, grid, stats, grDevices, rlang; drop parameters/tidyverse); `Suggests`: brms, ordinal, testthat, knitr, rmarkdown; `Config/testthat/edition: 3`; `Roxygen: list(markdown = TRUE)`; version 0.2.0.
- brms and ordinal move to Suggests: users who pass a `brmsfit`/`clm` necessarily have them installed; runtime guards via `rlang::check_installed()`. This keeps the hard dependency footprint reasonable.
- `LICENSE` becomes the CRAN 2-line form; full text moves to `LICENSE.md` (.Rbuildignore'd).
- `inst/CITATION`: package + the 2026 paper.
- `NEWS.md` documenting all user-facing changes.
- `zzz.R` joke startup message removed.
- Example PNGs move to `man/figures/`.

### 2. Code hardening (R/)

Bug fixes:
- `rvar_cumsum()` corrupts length-1 input (`2:length(x)` counts down). Guard with `seq_len`.
- `SDT_distributions_plot()`: scalar `ifelse()` misuse (drops names, evaluates fragile branches) → `if/else`; `coef(model)[1:max(...)-1]` precedence accident → `seq_len(n_thresholds)` derived from the response factor.
- Bayesian latent-distribution plots reference hardcoded publication coefficients (`b_targetfake`, `b_timepostXtargetfake`, …) and hardcoded legend labels ("True tweets"/"Fake tweets") and threshold labels (`1:12 | 2:13` vs `1:6 | 2:7`). All derived from the model/factor levels instead; optional label args added.
- `library(tidyverse|tidybayes|patchwork)` calls inside a function removed.
- `ggpubr::text_grob` (undeclared heavy dep) → `grid::textGrob`.
- `ordinal_model_ppd_check()`: positional column indexing (`model_data[, 2:vars+1]`) replaced by an explicit `group_vars` character argument; facet layout computed, not hardcoded.

Refactor:
- The 2-var and 3-var Bayesian latent-distribution functions duplicate ~300 lines. Extract one internal helper that, given a set of mean coefficients and disc coefficients, returns a posterior density band (`mean = sum(b_j)`, `sd = exp(-sum(b_disc_j))`, `tidybayes::curve_interval`). Each panel becomes a small spec.
- Shared internal plot theme helper for the serif title styling repeated in every function.
- Input validation helpers (`R/checks.R`): model class, variable-in-model, 2-level factor, CI in (0,1), `match.arg` for centrality — clear, early error messages.
- `utils::globalVariables()` declarations for NSE column names.

API policy (pre-1.0, documented in NEWS as breaking):
- Exported names stay. `var_signal`/`var_group` lose their study-specific defaults ("target"/"time") and become required.
- `response`/`response_scale` derived from the model when not supplied.
- `filename`/`path`/`width`/`height` ggsave-passthrough args removed from all functions; users call `ggplot2::ggsave()` (README shows how).

### 3. Example data

`sdt_ratings`: simulated trial-level dataset matching the publication's structure — id, condition (control/inoculation), time (pre/post), target (true/fake), value (ordered 1–6), generated from a probit SDT model in `data-raw/sdt_ratings.R` (seeded). Makes examples, tests, and the vignette self-contained.

### 4. Tests (testthat 3e)

- Unit: `rvar_cumsum` (incl. length-1), `bayesian_CI_bands` shape, validation errors for every check, theme/label helpers.
- Integration (frequentist): `ordinal::clm` fit on `sdt_ratings` → `roc_plot()`/`SDT_distributions_plot()` return ggplot objects with expected layers; `skip_if_not_installed("ordinal")`.
- Integration (Bayesian): small pre-fit `brms` fixtures (cumulative probit + disc; meta-analysis) generated by `data-raw/make_test_fixtures.R`; tests `skip_if` fixture missing, `skip_on_cran`. Fixtures committed only if small enough (≲2 MB each).

### 5. Docs

- Full roxygen (markdown) for all exports: real titles, `@param` with types/expectations, `@return`, `@examples` (frequentist runnable, brms in `\donttest`/not run), `@seealso`, package-level `_PACKAGE` doc.
- README: what/why, installation, quick-start with code, gallery, citation, related work.
- Vignette `visualizing-ordinal-models.Rmd`: dataset intro → clm workflow (evaluated when ordinal available) → brms workflow (code shown, not evaluated) → interpretation guidance.
